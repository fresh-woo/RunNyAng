# 📜 RunNyAng (런냥) - 게임 기획서 (Game Design Document)

## 1. 게임 개요 (Game Overview)
*   **게임명**: RunNyAng (런냥)
*   **플랫폼**: 반응형 모바일/PC 웹앱 (Responsive Web App / PWA / WebView 친화형)
*   **장르**: 2D 캐주얼 사이드스크롤 런닝 액션
*   **개발 스택**: React + TypeScript + Vite + HTML5 Canvas API
*   **타깃 유저**: 모바일/웹 환경에서 짧은 호흡으로 캐주얼하게 즐길 수 있는 미니게임을 선호하는 유저

---

## 2. 핵심 게임 메커니즘 (Core Mechanics)

### 2.1 이동 및 플레이어 조작
*   **자동 전진**: 캐릭터는 항상 우측 방향으로 기본 속도로 질주합니다.
*   **단일 점프**: 지상 장애물 또는 구덩이를 뛰어넘습니다.
*   **2단 점프**: 공중에서 한 번 더 도약하여 높은 장애물을 넘거나 공중 코인을 획득합니다.
*   **슬라이딩 (숙이기)**: 캐릭터의 높이를 낮춰 상단 공중 장애물을 통과합니다.

### 2.2 반응형 디바이스별 조작 매핑
| 플랫폼 | 점프 (Jump) | 슬라이딩 (Slide) |
| :--- | :--- | :--- |
| **PC (키보드)** | `Space` 또는 `Arrow Up (↑)` | `Arrow Down (↓)` |
| **모바일 / 태블릿 (터치)** | 화면 터치 / 탭 (Tap) | 화면 아래로 스와이프 (Swipe Down) / 별도 버튼 터치 |

## 3. 엔티티 및 시스템 구성 (Entities & Systems)

### 3.1 플레이어 캐릭터 (Player)
*   기본 상태: `Running`
*   조작 상태: `Jumping`, `Double-Jumping`, `Sliding`
*   특수 상태: `Hit (Game Over)`, `Invincible (무적)`

### 3.2 장애물 (Obstacles)
1.  **지상 장애물 (Ground Obstacle)**: 바위, 가시 등 (점프로 회피)
2.  **공중 장애물 (Flying Obstacle)**: 날아오는 새, 낮은 나뭇가지 등 (슬라이딩으로 회피)

### 3.3 아이템 (Collectibles)
*   **코인 (Coin)**: 획득 시 점수 가산 및 재화 축적
*   **속도 증가 (Speed Boost)**: 이동 속도가 빨라지며 고득점 기회 부여

### 3.4 난이도 곡선 (Difficulty Pacing)
*   달린 거리(Distance)가 500m 단위로 누적될 때마다 게임 속도가 점진적으로 가속됩니다.
*   장애물 간 스폰 주기가 짧아져 반사신경 요구도가 상승합니다.

## 4. UI 및 화면 흐름 (Screen Flow)
1.  **시작 화면 (Ready Screen)**:
    *   타이틀 로고, 시작 버튼, 조작 가이드 안내
2.  **인게임 HUD (In-Game Screen)**:
    *   달린 거리(m), 수집한 코인 수, 최고 기록 실시간 표시
3.  **게임 오버 화면 (Game Over Modal)**:
    *   이번 판 달린 거리, 획득 코인, 최고 기록 갱신 여부
    *   '다시 달리기' 버튼
