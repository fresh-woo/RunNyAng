# 📜 RunNyAng (런냥) : 중앙대편 - 게임 기획서 (Game Design Document)

## 1. 게임 개요 (Game Overview)
*   **게임명**: RunNyAng (런냥) : 중앙대편
*   **배경**: 중앙대학교 서울캠퍼스 (Chung-Ang University Seoul Campus)
*   **플랫폼**: 반응형 모바일/PC 웹앱 (Responsive Web App / WebView 최적화)
*   **장르**: 2D 쿼터뷰/대각선 시점 캠퍼스 런닝 액션 (스테이지 클리어형)
*   **개발 스택**: React 18 + TypeScript + Vite + HTML5 Canvas API
*   **아트 스타일**: 귀여운 레트로 픽셀(도트) 그래픽

---

## 2. 플레이어 캐릭터 & 애니메이션 시스템
*   **캐릭터**: 중앙대 캠퍼스를 누비는 귀여운 고양이 (RunNyAng)
*   **달리기 애니메이션**: 2~3장의 스프라이트 프레임(Frame 0, 1, 2)이 100~120ms 주기로 교차되며 리드미컬한 질주 모션을 연출.
*   **더미 및 확장 구조**:
    *   현재: 캔버스 기반 3프레임 도트 고양이(발/귀/꼬리 교차) 더미 작동
    *   디자인 에셋 완료 시: 2~3장의 투명 PNG 스프라이트를 배열로 넘기면 즉시 교체 가능.

---

## 3. 조작 및 이동 메커니즘 (Free Movement)
*   3개 레인에 갇히지 않고, 캠퍼스 도로 폭 안에서 **자유롭게 좌우로 회피 이동**.
*   자동 전진 주행 + 상/하 키를 통한 순간 가속 및 감속 지원.

| 플랫폼 | 좌/우 이동 (회피) | 가속 (Boost) | 감속 (Brake) | 시작 / 재시작 |
| :--- | :--- | :--- | :--- | :--- |
| **PC (키보드)** | `← / →` 또는 `A / D` | `↑` 또는 `W` | `↓` 또는 `S` | `Space` / `Enter` |
| **모바일 (터치)** | 화면 좌측/우측 터치 분할 | (추후 제스처 추가) | (추후 제스처 추가) | 화면 탭 |

---

## 4. 스테이지 레벨 디자인 (Stage 1: 정문 ➔ 310관)

랜덤 생성이 아닌, **수작업(Handcrafted) 맵 데이터** 구조로 제작되어 누구나 쉽게 랜드마크와 장애물 좌표를 배치/수정할 수 있습니다.

```
[출발: 중앙대 정문] (0m)
       │
       ▼
 [영신관 101관] (550m) ➔ 방치된 전동 킥보드 장애물
       │
       ▼
 [청룡연못 / 청룡탕 🐉] (1,050m) ➔ 쏟아진 아이스 아메리카노 & 물웅덩이
       │
       ▼
 [공포의 헐떡고개 ⛰️] (1,400m ~ 1,800m) ➔ 굴러떨어지는 전공서적 & 공사 라바콘
       │
       ▼
 [빼빼로 광장] (2,200m) ➔ 바람에 날리는 시험지 뭉치
       │
       ▼
[도착: 310관 100주년 기념관 🏁] (3,000m) ➔ 🎉 STAGE CLEAR!
```

### 4.1 수집 아이템 (Collectibles)
*   **츄르 (Churu)**: 길가 곳곳에 놓인 고양이용 간식. 수집 시 스코어 가산 및 클리어 정산에 반영.

---

## 5. UI 및 화면 흐름 (Screen Flow)
1.  **출발 안내 화면 (Ready Overlay)**: 스테이지 목표 및 조작법 안내
2.  **인게임 HUD**:
    *   상단: 현재 구간명, 수집한 츄르 개수
    *   프로그레스 바: 정문(0m)에서 310관(3000m)까지 고양이 발자국 아이콘이 실시간으로 전진
3.  **스테이지 클리어 모달 (Stage Clear)**: 310관 도착 시 소요 시간 및 수집 츄르 축하창
4.  **실패 모달 (Game Over)**: 장애물 충돌 시 달성한 % 진척도 확인 후 정문에서 재시작
